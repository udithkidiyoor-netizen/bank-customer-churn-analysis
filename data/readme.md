
## Dataset Features

| Column Name     | Data Type | Description                                                   |
| --------------- | --------- | ------------------------------------------------------------- |
| RowNumber       | Integer   | Sequential row number from 1 to 10,000                        |
| CustomerId      | Integer   | Unique customer identifier assigned by the bank               |
| Surname         | String    | Customer's last name                                          |
| CreditScore     | Integer   | Customer's credit score ranging from 300 to 850               |
| Geography       | String    | Customer's country of residence                               |
| Gender          | String    | Customer's gender                                             |
| Age             | Integer   | Customer's age in years                                       |
| Tenure          | Integer   | Number of years the customer has been with the bank           |
| Balance         | Float     | Customer's account balance in Euros                           |
| NumOfProducts   | Integer   | Number of bank products owned by the customer                 |
| HasCrCard       | Boolean   | Indicates whether the customer has a credit card              |
| IsActiveMember  | Boolean   | Indicates whether the customer is an active member            |
| EstimatedSalary | Float     | Customer's estimated annual salary in Euros                   |
| Exited          | Boolean   | Target variable indicating whether the customer left the bank |
